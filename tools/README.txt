Godot Engine 4.7.2 (stable, win64)
==================================

These files are the Godot game engine itself, not part of the game.

  Godot_v4.7.2-stable_win64.exe          the engine (runs the game / editor)
  Godot_v4.7.2-stable_win64_console.exe  a small wrapper that also prints text

Godot is free and open source, under the MIT license.
Website: https://godotengine.org
Source:  https://github.com/godotengine/godot
License: https://godotengine.org/license

You can delete this folder at any time. The game will still open in any
Godot 4.7+ editor installed on the computer.
